# INA BASEBALL
高校野球のスコア・配球・打球分析アプリの試作。

## 開発
Node.js 24 / npm 11 で確認済み。

```sh
npm ci
npm run dev -- --port 5173
```

## 検証
```sh
npm run build
node --test tests/record.test.js
```

## 現在の範囲
- 球種・コース・打球位置と打席結果を記録
- コースはマス目を残し、タップした自由位置にマーク。端末サイズに依存しない座標を保存
- キーボードではコース図にフォーカスし、矢印キーで調整、Deleteで解除
- カウント・攻守交代の計算、直前の記録取り消し
- 球種割合・打球分布、記録一覧印刷、JSON書き出し
- ブラウザのlocalStorageに1試合保存。新しい試合で置き換え

両チームのスタメン（打順・選手名・背番号・守備位置）を登録・修正できます。
入力途中も自動保存し、登録した選手名を打者・走者・印刷へ反映します。
DHの有無をチームごとに設定できます。DHありは打順9人（DHを含む）と打順外の先発投手を別枠で登録します。
先発投手は記録画面と印刷に反映し、投手を含めて背番号の重複を確認します。
投手兼DH・DH解除・試合途中の交代ルールは未対応です。
共同編集、認証、選手交代、正式なスコアブックは未実装。
四死球の強制進塁・押し出し、本塁打の全走者生還、走塁死に対応。
打席終了時（安打・四死球・三振・アウトなど）に確認画面を表示。
打者と各走者の到達塁・生還・アウトを選択し、一つのプレーとして保存します。
同塁への重複・走者の追い越し・3を超えるアウト数は入力できません。
第3アウト時の生還は原則無得点とし、得点を認める場合だけ確認欄をオンにします。
フォースアウトなどの判定・生還との前後関係は記録者による確認が必要です。
併殺・犠牲フライの走者と得点は記録できますが、打席結果の分類・守備記録は今後対応。
確定前はキャンセルでき、確定後は直前のプレーを取り消して入力し直せます。
打席途中の追加進塁は走者欄で入力できます。既存データも引き続き読み込めます。
イニング別得点を集計し、延長回も表示。
ブラウザのデータ削除に備えてJSONを書き出してください。JSON再読込は未実装。

## GitHub Pages
リポジトリの Settings → Pages → Build and deployment → Source を
**GitHub Actions** に設定してください。mainへのpushでテスト・ビルド後、distを公開します。
アセットは相対パスのため `/inabaseball/` 配下でも読み込めます。
